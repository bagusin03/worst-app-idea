FernCall: one sentence pitching the worst app idea imaginable, for make.fun's "The Worst App Idea Ever Pitched" bounty. `main.ts` writes a single 237-character sentence to `/output/entry.txt` — nothing else. Fully offline and deterministic: no network, no clock, no randomness, standard library only. A runtime guard enforces the gate (1–240 characters, one sentence, not only whitespace) before writing.

> FernCall is the app that lets your houseplants video-call each other while you're out, so your fern can gossip with the neighbour's cactus about how little you water them — premium plan lets the cactus reply, for $10 a month, no refunds.

## Run it

```sh
node main.ts
```
